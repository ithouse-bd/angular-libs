Data Table — server mode

The table emits sort/search/filter/page/pageSize changes; the demo fakes an API call (400 ms) over 47 users and sends back one page at a time. The Role column uses a select filter, so only the matching roles are fetched back.

Cascading select (dependent dropdown)

Division → District → Sub-district, any depth. Only the divisions ship with the page — each child level is fetched with a simulated 600 ms API call, cached, and shown with its own placeholder (“Select District”, “Select Sub-district”). Typing searches the whole tree on the server (300 ms debounce + simulated 400 ms request), so levels never have to be loaded first.
